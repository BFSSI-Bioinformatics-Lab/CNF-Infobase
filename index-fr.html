Fichier canadien sur les éléments nutritifs (FCÉN) 2026 de Santé Canada:

Un outil interactif pour visualiser le profil nutritionnel des aliments inclus dans la base de données 2026

  • Dernière mise à jour : REMPLACER MOI: (yyyy-mm-dd)

Cet outil vous aidera à visualiser les valeurs nutritives moyennes pour des aliments offerts au Canada inclus dans le Fichier canadien sur les éléments nutritifs 2026. Utilisez l’outil pour trouver les valeurs détaillées jusqu’à 173 éléments nutritifs, notamment :

  • les lipides,
  • l’énergie,
  • les protéines,
  • les vitamines, et
  • les minéraux.
